# NebulaOS test builds

Test builds made to investigate a specific problem, linked from the issue they belong to.
**They are not normal releases.** Only install one if you were asked to in an issue, and if
you are willing to send logs back.

Normal NebulaOS releases, documentation and support are in
[NebulaOS-KE/NebulaOS](https://github.com/NebulaOS-KE/NebulaOS).

Each release here says which issue it is for, what it changes, the exact source commits, and
how to go back to the normal release.
